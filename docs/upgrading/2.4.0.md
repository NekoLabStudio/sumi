# Sumi 2.4.0


## Inkstead Writer is now Sumi

Inkstead Writer and its Plume template language are now one project called Sumi. The command is `sumi`, the configuration is `sumi.json` and templates use `.sumi`.

The old `./inkstead-writer` command can't download Sumi, so install Sumi first. On macOS:

```bash
brew install nekolabstudio/tap/sumi
```

On Linux, or without Homebrew:

```bash
curl -fsSL https://oss.nekolab.studio/sumi/install.sh | sh
```

Then run any command in your site, such as `sumi doctor`. Sumi moves the site over on its first run and lists each change for you to review and commit. If a new name is already taken, it changes nothing and tells you which files to sort out.

Two things are yours to change:

- Swap the Plume editor extensions for the Sumi ones attached to each [release](https://github.com/NekoLabStudio/sumi/releases/latest).
- If you edited your theme's footer, remove the Inkstead credit by hand. Sumi names the file.

## Also new

- The default footer no longer carries a credit, and `theme.showPoweredBy` is gone.
- The Inkstead app's settings in `sumi.json` are now called `inkstead`.
- `sumi mcp` lets AI coding agents read the Sumi docs and your site's configuration. See [Commands](/start/commands/#ai-coding-agents).
- The template language has its own guides, starting with [Syntax](/templates/syntax/).
